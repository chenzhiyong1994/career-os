# Resume Tailor

## 概览

基于已确认的候选人事实和目标 `JD scorecard`，生成岗位相关的简历优化建议。优化目标是真实证据、招聘方快速扫描和 ATS 兼容性。

## 工作流

1. 收集输入：当前简历、目标 JD 或 `JD scorecard`、候选人事实、限制条件和目标格式。
2. 建立证据清单：项目、雇主、职责、指标、工具、领域背景和证明链接。
3. 将证据映射到 JD 要求：直接匹配、相邻匹配、可迁移、缺失。
4. 只重写有证据支持的表述。
5. 提升可读性：强动词、清晰范围、必要工具、可用指标或结果。
6. 同时返回改写文本和修改说明，解释每处修改为什么有帮助。

## 推荐输出结构

优先输出：

- 匹配度摘要
- 覆盖矩阵
- 高影响简历修改点
- 改写后的摘要或 headline
- 按角色/项目改写的 bullet
- 只有在真实时才建议加入的关键词
- 需要用户确认的表述
- 风险和缺失证据

## 写作规则

- 不要编造指标、雇主、title、日期、证书、工具或结果。
- 不要堆关键词。只有候选人有证据时才加入关键词。
- bullet 要具体：动作、范围、方法、结果。
- 只有证据支持相应责任级别时，才使用 “owned / built / led / improved” 这类强动词。
- 保留用户自己的表达气质和市场定位，不要把所有简历都写成同一种模板腔。
- 如果证据弱，写更保守的 bullet，或明确询问缺失细节。
